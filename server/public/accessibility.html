Accessibility

CMCEN is designed to make information and services usable by as many people as possible.

Keyboard navigation

You can use the site without a mouse. Press the Tab key to move through links, buttons, form fields, and menus; Shift + Tab moves backwards. The current keyboard focus is shown with a visible outline.

At the beginning of each page, a “Skip to main content” link lets keyboard users move past the site header and navigation. Menu and disclosure controls report whether they are expanded, and can be operated with the keyboard.

Display and motion

Use the appearance control in the site footer to switch between light and dark colour themes. The site adapts to phones, tablets, and desktop screens, so content can be read without relying on a fixed screen size.

When your device is set to reduce motion, the site reduces non-essential visual motion and transitions.

Language

Use the language control in the site header to switch between English and French. Dates and other localized information follow the selected language where available.

Forms and updates

Form fields have labels and validation messages. Where a page updates without reloading, such as while content is loading or a character count changes, status information is announced to assistive technology.

Feedback and assistance

If you have difficulty using a page, need information in another format, or want to report an accessibility issue, please contact us. Include the page address and a brief description of the problem so we can help.
